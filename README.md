
# Python Data Analysis using NumPy and Pandas

## Overview
This project focuses on basic data analysis using Python, NumPy, and Pandas. It covers numerical calculations, array operations, data manipulation, and data exploration.

## Topics Covered

### 1. NumPy Array Operations
- Creating 1D and 2D NumPy arrays
- Checking array shape, data type, and size
- Celsius to Fahrenheit conversion
- Finding maximum, minimum, and mean values
- Array indexing and slicing

### 2. Pandas Series
- Creating Pandas Series with custom indices
- Accessing values using `loc` and `iloc`
- Filtering data using Boolean masking
- Modifying and removing Series entries
- Calculating CGPA

### 3. Pandas DataFrame
- Creating a DataFrame
- Exploring data using `head()`, `tail()`, `shape`, `columns`, and `dtypes`
- Selecting specific columns
- Filtering rows using conditions
- Finding value counts and unique values
- Grouping data and calculating mean values
- Adding, modifying, and deleting rows and columns
